# Guion de demostración

1. Coordinador crea convocatoria, cursos, actividades y fechas.
2. Postulante de prueba solicita inscripción y carga evidencia ficticia.
3. Tutor revisa, comenta y registra contacto/compromiso.
4. Se muestra condición de riesgo y notificación simulada.
5. Coordinador consulta dashboard, trazabilidad y exporta PDF/Excel.

## Preparación
- [ ] Cuentas demo.
- [ ] Datos seed.
- [ ] Archivos ficticios.
- [ ] Escenario de alerta reproducible.
- [ ] Reportes probados.
- [ ] Aplicación local funcionando.

No editar manualmente la base durante la demostración.
