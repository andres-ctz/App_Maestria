# Backend

Responsabilidad: API, reglas de negocio, validaciones, autorización y persistencia.

Módulos propuestos: Auth, Users/Roles, Assignments, Institution, Faculties, Programs, Periods, Calls, Applications, Admissions, Enrollments, Courses, Groups, Activities, Assessments, Grading, FollowUp, Risk, Notifications, Files, Audit, Reports y Setup (asistente de configuración inicial).

Validar entradas, aplicar permisos por rol y asignación (ver [[Matriz de permisos]]), usar transacciones en operaciones sensibles (por ejemplo, asignación de cupos) y proteger las descargas.
