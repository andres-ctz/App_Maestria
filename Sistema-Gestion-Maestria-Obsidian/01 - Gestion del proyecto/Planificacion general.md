# Planificación general

**Estado:** propuesta para validar. **Plazo:** 4 semanas (20 días laborables). **Equipo:** 5.

## Objetivo
Construir una aplicación web para gestionar programas, convocatorias, postulantes, cursos, actividades, evidencias, seguimiento tutorial, alertas y reportes.

## Entrega inicial
Versión local funcional y documentada, con datos ficticios y correos simulados. Despliegue y migración real después de aprobación.

## Principios
- Priorizar flujos completos y seguros.
- Validar permisos en backend.
- Mantener documentos privados.
- Integrar cambios continuamente.
- Registrar decisiones y supuestos.
- Probar desde la primera semana.
