# Checklist de entrega

Basado en los criterios de aceptación del v0.3 §22.

- [ ] Instalación limpia siguiendo el README.
- [ ] Cuentas demo para los cuatro roles.
- [ ] Los roles y asignaciones delimitan el acceso; el backend bloquea lo no autorizado.
- [ ] El administrador gestiona la estructura institucional.
- [ ] El coordinador administra solo sus programas.
- [ ] Las convocatorias se publican y consultan según su estado.
- [ ] El postulante completa y envía su postulación con documentos.
- [ ] Los documentos se revisan y conservan sus versiones.
- [ ] Admisiones y lista de espera respetan cupos y orden.
- [ ] Las matrículas relacionan estudiantes y cursos.
- [ ] Las actividades se publican, entregan, revisan y califican.
- [ ] Las entregas grupales conservan los integrantes históricos.
- [ ] Las evaluaciones controlan tiempo e intentos y conservan las preguntas usadas.
- [ ] Las ponderaciones respetan las categorías institucionales.
- [ ] Las calificaciones se cierran y publican por separado; lo publicado no cambia.
- [ ] El seguimiento académico conserva su historial.
- [ ] Las notificaciones respetan preferencias y no se duplican.
- [ ] Correos simulados visibles en la herramienta local.
- [ ] Los archivos se validan y no se descargan sin autorización.
- [ ] Los reportes respetan el alcance y coinciden con los datos guardados.
- [ ] Las operaciones importantes quedan auditadas.
- [ ] Interfaz adaptable a escritorio y móvil.
- [ ] Respaldo y restauración documentados.
