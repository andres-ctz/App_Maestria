# Modelo de datos conceptual

> [!warning] Preliminar: cardinalidades y reglas dependen de respuestas del cliente.

| Entidad | Propósito |
|---|---|
| User / Role | Usuarios, credenciales y roles |
| Program / Call | Programas y convocatorias |
| TutorAssignment | Asignación tutor-postulante |
| Application | Inscripción a convocatoria |
| Course / Enrollment | Cursos y participación |
| Activity / ActivitySubmission | Actividades y entregas |
| Evidence / EvidenceReview | Archivo, versión y revisión |
| TutoringContact / Commitment | Contactos y compromisos |
| Notification | Recordatorios y estado |
| RiskAssessment | Nivel, motivos y fecha |
| AuditLog | Actor, acción, entidad y fecha |

Definir cardinalidades, claves, restricciones y estados antes de migraciones definitivas.
