# Vault del proyecto

Este Vault combina documentación compartida y espacio personal.

- `00 - Inicio` a `07 - Entrega`: documentación del equipo.
- `90 - Personal`: notas privadas de cada integrante, excluidas de Git.
- `99 - Recursos`: documentos de referencia.

## Abrir
Descomprime el ZIP y en Obsidian selecciona **Abrir carpeta como bóveda**. Elige esta carpeta y abre `00 - Inicio/Dashboard.md`.

## Trabajo compartido
Si guardan este Vault dentro del repositorio Git, la carpeta `90 - Personal/` queda excluida mediante `.gitignore`. No guardar secretos, credenciales ni datos reales de postulantes. GitHub debe seguir siendo el registro oficial de Issues y Pull Requests; Obsidian es la documentación.
